# Задача: апгрейд фото-распознавания в Nauryz AI (Haiku → Sonnet)

## Контекст
Nauryz AI — веб-приложение для казахстанских фермеров-птицеводов. Есть функция загрузки фото (больная птица, помёт, состояние птичника), которая анализируется через Claude Haiku. Нужно перейти на Sonnet для более точного распознавания.

## Что нужно сделать

1. Найти в коде текущую интеграцию vision API (скорее всего API route с вызовом Anthropic API и изображением).

2. Заменить модель с `claude-haiku-4-5-20251001` на `claude-sonnet-5` (проверить актуальную строку модели в коде).

3. Пересмотреть system-промпт для фото-анализа — с более сильной моделью дать более детальные инструкции: структурированный ответ (симптомы → вероятные причины → рекомендации → когда обращаться к ветеринару).

4. Проверить обработку изображений: формат base64, media_type, лимиты размера — не изменились ли требования при смене модели.

5. Учесть стоимость: Sonnet дороже Haiku за токен. Прикинуть, оправдана ли замена для всех фото-запросов, или сделать двухступенчатую схему (сначала быстрый Haiku-скрининг, Sonnet — при неуверенности).

6. Протестировать на реальных фото из текущей базы (если есть тестовый набор с известным правильным диагнозом) — сравнить точность до/после.

7. Обновить .env / конфиг, если модель зашита не как константа, а через переменную окружения.

8. **Prompt caching для экономии**
   - Статичный system-промпт (правила диагностики, формат ответа, контекст птицеводства) вынести в отдельный блок с `cache_control: {"type": "ephemeral"}`.
   - Кэшированные токены дешевле примерно в 10 раз — особенно важно при переходе на Sonnet.
   - Убедиться, что кэш переиспользуется между запросами разных пользователей, если промпт одинаковый для всех.
   - Проверить TTL кэша (обычно 5 минут) — при низком трафике кэш может не успевать "прогреваться".
   - Добавить логирование `cache_creation_input_tokens` и `cache_read_input_tokens` из ответа API для отслеживания реальной экономии.

## Результат
Дать diff по изменённым файлам и краткий отчёт: что поменялось, какие тесты прогнаны, есть ли риски по стоимости.
