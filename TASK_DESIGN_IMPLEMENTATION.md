# Задача: реализация редизайна Nauryz AI в реальном коде

## Контекст
Есть готовый design handoff пакет от Claude Design (папка `design_handoff_nauryz_ai/`) — тёплый земляной ("agro") редизайн интерфейса. Это HTML-прототипы для референса, НЕ код для копирования напрямую. Нужно воссоздать этот дизайн внутри реального Next.js-приложения, используя существующий слой состояния/данных (сообщения чата, загрузка фото, RAG-результаты) и реальные API-вызовы к vision/chat-бэкенду.

Полное описание — в `design_handoff_nauryz_ai/README.md` (уже внутри архива), обязательно прочитать перед началом — там подробно расписаны все 5 экранов, дизайн-токены, состояние, анимации.

## Что нужно сделать

### 1. Изучить материалы
- Прочитать `README.md` целиком
- Открыть `Nauryz AI - Mobile.dc.html` и `Nauryz AI - Web.dc.html` в браузере, чтобы увидеть прототип вживую
- Изучить `_ds/organic-.../styles.css` — источник истины по всем дизайн-токенам (цвета, шрифты, радиусы, тени)

### 2. Перенести дизайн-токены
Добавить в проект CSS-переменные из `styles.css` (цвета, шрифты Caprasimo/Figtree, радиусы, тени, tonal ramps для neutral/accent/accent-2, включая тёмную тему). Не изобретать новые значения — использовать один в один из токенов.

### 3. Реализовать экраны/компоненты (по приоритету)
1. **Пустое состояние** (приветствие + карточки быстрых вопросов) с приветственной анимацией (fade-up + каскад карточек, с учётом `prefers-reduced-motion`)
2. **Лента чата** — пузыри сообщений (юзер справа/ассистент слева), typing-индикатор, indicator анализа фото
3. **Карточка диагноза** — структурированный ответ с тегами (Осмотр/Симптомы/Причины), топ-2 причины с процентами, кнопка "Подробный разбор →"
4. **Модалка/полноэкранный лист диагноза** — полный список причин с severity-цветами, рекомендации с нумерацией
5. **Калькулятор корма** — быстрый инлайн-вариант в чате (при клике на "Норма корма для бройлеров") + отдельная полноценная модалка через кнопку в шапке (⚖️ Калькулятор нормы корма)
6. **История чатов** — mobile: полноэкранная панель слева; desktop: постоянный сайдбар с collapse/expand
7. **Фоновые орнаменты** — низкая непрозрачность SVG-паттерн (пшеница/лист/яйцо/перо), генерируется по теме
8. **Тёмная тема** — переключатель, с учётом токена `--color-accent-onbg` для акцентного текста на фоне (описанный в README баг-паттерн — не хардкодить accent-700/800 текст на фоне, который меняется в тёмной теме)
9. **Переключатель языка ҚАЗ/RU** — для интерфейсных подписей (кнопки, заголовки, калькуляторы); глубокий контент (диагнозы/рекомендации) пока остаётся только на русском — это осознанное ограничение, не баг

### 4. Важные технические детали
- Иконки — заменить плейсхолдерные inline-SVG на нормальный icon-set (Lucide, stroke-width 2.75)
- Фото-превью — заменить `image-slot.js` (плейсхолдер) на реальную интеграцию с существующим пайплайном загрузки/vision-анализа
- Логика уточняющих вопросов при неполном описании симптомов ("Курица хромает" → сначала уточняющие вопросы про возраст/ногу/позу/условия, а не мгновенный диагноз) — это должно быть реальным поведением бэкенда (system-промпт), не просто заскриптованным в дизайне

### 5. Порядок работы
Рекомендую поэтапно: сначала токены + пустое состояние + лента чата (самое используемое), закоммитить, показать превью → затем модалка диагноза + калькулятор → затем история/сайдбар → затем полировка (орнаменты, анимации, тёмная тема, языковой переключатель). Не пытаться сделать всё одним огромным коммитом — проще ревьюить и тестировать по частям.

### 6. Тестирование
После каждого крупного этапа — показать скриншот/превью на dev-сервере, чтобы сверить с прототипом перед тем как двигаться дальше.

## Результат
Отчёт по каждому этапу: что реализовано, какие отклонения от прототипа пришлось сделать и почему (если были), скриншоты/превью для сравнения с оригинальным дизайном.
